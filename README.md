# UPGMA Gower-Distance Cluster Analysis of *P. aeruginosa* Strains

## Purpose

Reproducible computational workflow for UPGMA hierarchical clustering of 56 *Pseudomonas aeruginosa* isolates using a Gower-type mixed-variable distance matrix. Corrects the inappropriate use of Euclidean distance on integer-coded categorical variables.

## Dataset

- **File**: `input_data.csv` (56 isolates × 23 columns)
- **Correction applied**: 62F3 pigment = Pyomelanin (not Pyocianin)
- **22 variables**: 12 antibiotics (ordinal 0/1/2), exoS, exoU, Pro, AP, EX, ST, Gen (binary), Pig (nominal), BF (ordinal), Age (continuous)
- **Missing values**: 0 (NaN-aware handling active but no missing values present)

## Distance Calculation (Gower-type)

| Variable Type | Variables | Distance |
|--------------|-----------|----------|
| Ordinal (antibiotics) | LEV, CIP, OFX, IPM, AN, TOB, GM, CAZ, PTZ, AZT, MEN, FEP | \|xᵢ-xⱼ\|/2 |
| Continuous | Age | \|Ageᵢ-Ageⱼ\|/(max-min) |
| Binary | exoS, exoU, Pro, AP, EX, ST, Gen | 0 if same, 1 if different |
| Ordinal (biofilm) | BF (Neg=0, Weak=1, Mod=2, Strong=3) | \|BFᵢ-BFⱼ\|/3 |
| Nominal | Pig | 0 if same, 1 if different |

**D(i,j) = sum(valid) / count(valid)** — NaN-aware (missing values excluded per pair).

## Clustering

- **Method**: UPGMA (average linkage)
- **Input**: Precomputed Gower distance matrix (NOT Euclidean)
- **Software**: `scipy.cluster.hierarchy.linkage(method="average")`

## Silhouette Results

The script evaluates silhouette scores for **k = 2–6** using the precomputed Gower-type distance matrix. These scores are comparative diagnostics; they do not, by themselves, determine the final groups shown in the manuscript. The final grouping is interpreted from the major branches of the UPGMA dendrogram, as described in the manuscript Methods.

## Requirements

```bash
pip install -r requirements.txt
```

## Reproduction

Run the analysis with:

```bash
python upgma_gower_analysis.py --input input_data.csv --output-dir output
```

The current script computes the Gower-type distance matrix, performs UPGMA clustering, evaluates silhouette scores for k = 2–6, and generates the heatmap. It writes the distance matrix and heatmap to the selected output directory; the silhouette results are reported in the console. Other CSV, Excel, methods, and validation files listed below are supporting artifacts included in the repository and are **not all regenerated by this script**.
